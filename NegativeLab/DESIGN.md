Visual thesis: a quiet charcoal photo workspace, warm white type and one amber accent, with the image taking most of the window.

Content plan: a small NegativeLab masthead; source, converter, optional SwinIR and editing controls in a left inspector; the source, converted results, paired comparison and SwinIR enlargement in a large tabbed viewer; progress and output-folder access at the bottom.

Interaction thesis: highlight the drop surface when a file approaches; reveal conversion results in place as each engine completes; switch between fitted images and a paired comparison without moving the inspector. Upscaling is always a separate manual action on a positive. A source selector lets existing positives bypass negative conversion. Respect reduced animation by using only short control-state transitions.
